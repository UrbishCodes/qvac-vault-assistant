# Welcome 👋

This is a demo vault for trying the **QVAC Vault Assistant** plugin — everything
here runs 100% on your device, no cloud, no API keys.

## Try this

1. Open **Book Notes - Deep Work** and press `Ctrl/Cmd+P` → **Summarize current note**.
2. Open **Meeting Notes** → **Extract action items from note**.
3. Open **Project Ideas** → **Find related notes…** — semantic search should surface
   the book notes, since they share ideas about focus and deep work.
4. Click the ⚡ ribbon icon → **Open Vault Assistant** and ask a question about the
   open note.

The first command downloads the model (~2 GB, one time). After that, no internet needed.
