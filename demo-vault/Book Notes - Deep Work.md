# Book Notes — Deep Work 📚
*Cal Newport*

## Core thesis
The ability to focus without distraction on cognitively demanding tasks is becoming
rare and increasingly valuable. Shallow work — email, meetings, social media —
feels productive but produces little. Deep work is what creates real leverage.

## Rules that stuck with me
1. **Work deeply** — schedule long, uninterrupted blocks; treat focus like a skill.
2. **Embrace boredom** — resist distraction even in idle moments to rewire attention.
3. **Quit social media** — audit tools by whether they substantially serve your goals.
4. **Drain the shallows** — batch emails and admin into fixed windows.

## My takeaways
- Attention is the scarcest resource I have; I should budget it like money.
- A 1B-parameter local model is "good enough" for summarizing precisely because
  summarization is a focus task — distilling signal from noise, the same thing
  deep work trains you to do.
- Want to try: two 90-minute deep-work blocks each morning before checking messages.
